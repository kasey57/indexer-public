      Szybki start

      1. Włącz Google Indexing API w projekcie Google Cloud.
      2. Utwórz konto usługi, pobierz jego klucz JSON i dodaj adres konta jako właściciela zweryfikowanej usługi w Search Console.
      3. Wybierz sposób pracy: wklej adresy stron albo zaimportuj mapę witryny. Przy pierwszym zgłoszeniu dla domeny wgraj klucz JSON.
      4. Sprawdź wyniki. Zgłoszenia oczekujące trafią do kolejki i zostaną przetworzone, gdy będzie to możliwe.

      Klucz konta usługi jest przechowywany w skonfigurowanej bazie, chyba że wybierzesz tryb prywatny. Zabezpiecz dostęp do aplikacji.
